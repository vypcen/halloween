# Хэллоуин 31.10 — сайт-приглашение

Одностраничный сайт: постер-приглашение, отметка «Буду / Не буду» с общим
счётчиком и комментарии. Свой сервер и своя база, без внешних сервисов.

## Что внутри

```
index.html        — страница (стили и скрипт внутри)
images/poster.jpg — постер-приглашение (положить вручную: тема.jpg)
images/icon.jpg   — лягушка-вампир, иконка (положить вручную: икон.jpg)
server.js         — сервер на Node.js, без зависимостей
data/db.json      — база: появится сама после первого ответа гостя
start.sh          — запуск на macOS / Linux
start.bat         — запуск на Windows
```

## Установка на втором ПК

1. Установите Node.js версии 18 или новее: https://nodejs.org (кнопка LTS).
2. Скопируйте папку `familySite` на этот ПК целиком.
3. Положите картинки в `images/` под именами `poster.jpg` и `icon.jpg`.
4. Откройте `start.sh` (macOS/Linux) или `start.bat` (Windows) и поменяйте
   код доступа `тыква` на свой. Чтобы пускать без кода, удалите строку с
   `SITE_CODE`.
5. Запустите:
   - Windows: двойной клик по `start.bat`
   - macOS / Linux: в терминале `./start.sh`

В окне сервера появятся адреса:
- `http://localhost:8080` — на самом этом ПК;
- `http://192.168.x.x:8080` — для телефонов и ноутбуков в той же Wi-Fi сети.

При первом запуске Windows или macOS может спросить, разрешить ли Node.js
входящие подключения. Разрешите для частной (домашней) сети.

## Как это работает

- Гость вводит код (если включён) один раз на устройстве.
- Ответ «Буду / Не буду» можно менять: нажатая кнопка неактивна, другая активна.
  Счётчик считает только «Буду».
- Гость узнаётся по случайному ключу, который хранится в его браузере.
  С другого браузера или после очистки данных сайта он будет новым гостем.
- Удалить можно только свой комментарий.
- Все изменения сразу появляются у всех, у кого открыта страница.

## Доступ из интернета (для друзей не из вашей сети)

Сервер виден только в домашней сети. Чтобы друзья открывали его из любого
места, есть два простых пути:

- **Cloudflare Tunnel** (бесплатно, без настройки роутера):
  установите `cloudflared` и запустите
  `cloudflared tunnel --url http://localhost:8080` — он выдаст адрес
  вида `https://что-то.trycloudflare.com`. Для постоянного адреса нужен
  аккаунт Cloudflare и свой домен.
- **Проброс порта на роутере**: порт 8080 → IP второго ПК. Нужен белый IP
  от провайдера; ссылка будет вида `http://ваш-ip:8080`.

При доступе из интернета обязательно оставьте включённым код доступа.

## Резервная копия и сброс

- Копия всех ответов и комментариев — файл `data/db.json`.
- Начать с чистого листа: остановите сервер и удалите `data/db.json`.

## Автозапуск

Чтобы сайт поднимался сам после перезагрузки ПК:
- Windows: положите ярлык на `start.bat` в папку автозагрузки
  (Win+R → `shell:startup`).
- macOS: Системные настройки → Основные → Объекты входа → добавить `start.sh`.
- Linux: `pm2 start server.js --name halloween && pm2 save && pm2 startup`
  (после `npm i -g pm2`).
